# Extended KeystoreManager

## Overview

The `KeystoreManager` is extended beyond the original ES256 FIDO2 signing to support all Android Keystore algorithms. This enables the phone to serve as a full HSM for elliptic curve signing, RSA signing/encryption, AES-GCM symmetric encryption, HMAC computation, and ECDH key agreement.

## Supported Algorithms

### Elliptic Curve

| Algorithm | Curve | Key Size | Coordinate Size | Signing |
|-----------|-------|----------|-----------------|---------|
| ES256 | P-256 (secp256r1) | 256 bits | 32 bytes | SHA256withECDSA |
| ES384 | P-384 (secp384r1) | 384 bits | 48 bytes | SHA384withECDSA |
| ES512 | P-521 (secp521r1) | 521 bits | 66 bytes | SHA512withECDSA |

### RSA

| Algorithm | Key Size | Signing | Padding |
|-----------|----------|---------|---------|
| RS256 | 2048-4096 | SHA256withRSA | PKCS1v15 or PSS |
| RS384 | 2048-4096 | SHA384withRSA | PKCS1v15 or PSS |
| RS512 | 2048-4096 | SHA512withRSA | PKCS1v15 or PSS |

### Symmetric

| Algorithm | Key Size | Mode | Notes |
|-----------|----------|------|-------|
| AES-128-GCM | 128 bits | GCM | 12-byte IV, 16-byte tag |
| AES-256-GCM | 256 bits | GCM | 12-byte IV, 16-byte tag |

### HMAC

| Algorithm | Key Size | Hash | Output |
|-----------|----------|------|--------|
| HMAC-SHA256 | 256 bits | SHA-256 | 32 bytes |
| HMAC-SHA512 | 512 bits | SHA-512 | 64 bytes |

## Methods

### Key Generation

**`generateKeyForAlgorithm(keyId: String, algorithm: String, authDuration: Int, strongBox: Boolean): PublicKey`**

Dispatches to the correct key generator based on algorithm. Returns the generated public key.

```kotlin
fun generateKeyForAlgorithm(
    keyId: String,
    algorithm: String,
    authDuration: Int = 5,
    strongBox: Boolean = true
): PublicKey {
    return when {
        algorithm.startsWith("ES") -> generateECKey(keyId, algorithm, authDuration, strongBox)
        algorithm.startsWith("RS") -> generateRSAKey(keyId, keySizeBitsFromAlg(algorithm), authDuration)
        algorithm.startsWith("AES") -> { generateSymmetricKey(keyId, keySizeBitsFromAlg(algorithm)); /* no public key */ }
        algorithm.startsWith("HMAC") -> { generateHMACKey(keyId, algorithm); /* no public key */ }
        else -> throw UnsupportedAlgorithmException(algorithm)
    }
}
```

**`generateRSAKey(keyId: String, keySizeBits: Int, authDuration: Int): PublicKey`**

Generates an RSA key pair in Android Keystore. Supports 2048, 3072, and 4096 bit keys. Configures both signing (PKCS1v15, PSS) and encryption (OAEP) purposes.

**`generateSymmetricKey(keyId: String, keySizeBits: Int)`**

Generates an AES key in Android Keystore. Configures GCM mode with no padding. Key sizes: 128 or 256 bits.

**`generateHMACKey(keyId: String, algorithm: String)`**

Generates an HMAC key in Android Keystore. Algorithm determines hash function and key size. Supported: `HMAC-SHA256` (256-bit key), `HMAC-SHA512` (512-bit key).

### Cryptographic Operations

**`signWithAlgorithm(keyId: String, data: ByteArray, algorithm: String): ByteArray`**

Algorithm-aware signing. Maps algorithm string to the correct `Signature` instance:

| Algorithm | Signature Instance |
|-----------|--------------------|
| ES256 | SHA256withECDSA |
| ES384 | SHA384withECDSA |
| ES512 | SHA512withECDSA |
| RS256 | SHA256withRSA |
| RS384 | SHA384withRSA |
| RS512 | SHA512withRSA |

Returns a DER-encoded signature for EC algorithms or PKCS#1 signature for RSA.

**`decrypt(keyId: String, ciphertext: ByteArray): ByteArray`**

RSA OAEP decryption using SHA-256 and MGF1. The key must have been generated with `PURPOSE_DECRYPT`.

**`symmetricEncrypt(keyId: String, plaintext: ByteArray, aad: ByteArray?): ByteArray`**

AES-GCM encryption. Returns `IV (12 bytes) || ciphertext || tag (16 bytes)`. The IV is generated by Android Keystore. Optional AAD (Additional Authenticated Data) is supported.

**`symmetricDecrypt(keyId: String, ciphertext: ByteArray, aad: ByteArray?): ByteArray`**

AES-GCM decryption. Input format: `IV (12 bytes) || ciphertext || tag (16 bytes)`. Returns decrypted plaintext. AAD must match what was used during encryption.

**`computeHMAC(keyId: String, data: ByteArray): ByteArray`**

Computes HMAC using the key's configured hash algorithm. Returns 32 bytes (SHA-256) or 64 bytes (SHA-512).

**`performECDH(keyId: String, peerPublicKey: PublicKey): ByteArray`**

ECDH key agreement using the local EC private key and a peer's public key. Returns the raw shared secret. The caller is responsible for running the shared secret through a KDF.

### Key Export

**`getPublicKeyDER(keyId: String): ByteArray`**

Exports the public key in DER (SubjectPublicKeyInfo) format.

**`getPublicKeyPEM(keyId: String): String`**

Exports the public key in PEM format (Base64-encoded DER with `-----BEGIN PUBLIC KEY-----` header).

**`getPublicKeySSH(keyId: String): String`**

Exports the public key in OpenSSH `authorized_keys` format. Supports EC and RSA keys. Format: `ecdsa-sha2-nistp256 AAAA...` or `ssh-rsa AAAA...`.

### Key Management

**`getKeyAttestation(keyId: String, challenge: ByteArray): List<Certificate>`**

Returns the Android Key Attestation certificate chain for the given key. The chain contains: leaf certificate (with attestation extension), intermediate certificate, and Google hardware attestation root.

**`listAllKeystoreAliases(): List<String>`**

Enumerates all key aliases in the Android Keystore managed by the app.

**`getKeyInfo(keyId: String): KeyInfo`**

Returns metadata about a key: algorithm, key size, purposes, security level (TEE/StrongBox), user authentication requirements, and creation date.

## Key Attestation

When generating a key, passing `setAttestationChallenge(nonce)` to `KeyGenParameterSpec.Builder` causes Android Keystore to embed attestation data in the key's certificate chain.

```kotlin
val spec = KeyGenParameterSpec.Builder(alias, PURPOSE_SIGN)
    .setAlgorithmParameterSpec(ECGenParameterSpec("secp256r1"))
    .setDigests(KeyProperties.DIGEST_SHA256)
    .setAttestationChallenge(nonce)
    .setIsStrongBoxBacked(true)
    .build()
```

**Certificate chain from `keyStore.getCertificateChain(alias)`:**

1. Leaf certificate with attestation extension
2. Intermediate certificate
3. Google hardware attestation root

**Attestation extension OID:** `1.3.6.1.4.1.11129.2.1.17`

The extension contains:
- Attestation version and security level (Software, TEE, StrongBox)
- Key characteristics (algorithm, purpose, digest)
- Challenge nonce (verifiable by the relying party)
- OS version and patch level
- Boot state and verified boot key

## StrongBox vs TEE Selection

```kotlin
try {
    builder.setIsStrongBoxBacked(true)
    keyPairGenerator.initialize(builder.build())
    keyPairGenerator.generateKeyPair()
} catch (e: StrongBoxUnavailableException) {
    // Fall back to TEE
    builder.setIsStrongBoxBacked(false)
    keyPairGenerator.initialize(builder.build())
    keyPairGenerator.generateKeyPair()
}
```

**StrongBox restrictions** (varies by device):

| Feature | TEE | StrongBox |
|---------|-----|-----------|
| P-256 (ES256) | Yes | Yes |
| P-384 (ES384) | Yes | Some devices |
| P-521 (ES512) | Yes | No |
| RSA 2048 | Yes | Some devices |
| RSA 4096 | Yes | No |
| AES-256-GCM | Yes | Yes |
| HMAC-SHA256 | Yes | Yes |

Algorithm availability is checked at runtime. `KeystoreManager` queries `KeyProperties` and catches `StrongBoxUnavailableException` to automatically fall back to TEE when StrongBox cannot support the requested algorithm.
